---

## 페르소나

| 항목 | 내용 |
|------|------|
| **대상** | 10명 규모 스타트업 팀리더 |
| **연령대** | 30~40대 |
| **핵심 불편** | 슬랙·노션·구두 보고가 뒤섞여 팀 현황 파악에 시간을 낭비 |
| **원하는 것** | 한 화면에서 누가 무엇을 하고 있는지 즉시 파악 |

---

## MVP 범위

### 포함

| 기능 | 세부 내용 |
|------|-----------|
| **태스크 CRUD** | 추가 / 목록 / 수정 / 삭제 — 4종 모두 화면에서 동작 |
| **상태 분류** | `todo` / `in_progress` / `done` |
| **마감 일시** | `due_at` — 날짜 + 시간까지 지정 (예: `2026-05-12 18:00`) |
| **라이트/다크 테마** | 토글 버튼, `localStorage` 유지 |
| **모바일 반응형** | 360px 기준, 1열 레이아웃으로 전환 |

### UI 톤 — macOS 스타일

- 둥근 모서리 (border-radius 12px 이상)
- 부드러운 그림자 (box-shadow, 낮은 채도)
- 반투명 카드 (backdrop-filter 또는 낮은 opacity 배경)
- 시스템 폰트 (`-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`)

## 확장 단계 (MVP 이후)

| 기능 | 단계 |
|------|------|
| JWT 로그인 | 2차 |
| 팀 / 멤버 관리 | 2차 |
| Kanban 드래그 앤 드롭 | 3차 |
| 채팅 (WebSocket) | 3차 |
| CI/CD 파이프라인 연동 | 4차 |

---

## 범위 외 (MVP에서 제외)

| 제외 항목 | 이유 |
|-----------|------|
| 외부 결제 | 수익 모델 미확정 |
| 네이티브 앱 (iOS/Android) | 웹 MVP 검증 후 결정 |
| WebRTC (화상·음성) | 전용 인프라 필요 |
| 외부 캘린더 연동 | OAuth 복잡도 |
| 파일 업로드 | 스토리지 인프라 필요 |
| WebSocket 실시간 | MVP는 폴링으로 대체, 확장 단계 보류 |

---

## 성공 기준

| 기준 | 목표 |
|------|------|
| 새로고침 후 데이터 유지 | 로그인 상태·태스크 목록 그대로 |
| 360px 레이아웃 | 가로 스크롤 없이 정상 표시 |
| API 응답 시간 | 200ms 이내 (p95) |
| CRUD 4종 화면 동작 | 추가·목록·수정·삭제 모두 UI에서 완료 가능 |
| 테마 토글 | 전환 즉시 반영, 새로고침 후에도 유지 |
